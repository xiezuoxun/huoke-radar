# 商机获客 · 线索雷达 —— 从零搭建指南

> 面向「要复刻一套类似平台」的同事。全程约 30 分钟，只需在 **Windows** 上操作。
> 前置：已安装 [WorkBuddy](https://www.workbuddy.cn)（含「资料库」skill）与 Python 3.11+。

---

## 0. 这套平台是什么

采集抖音/小红书**公开评论** → 识别购买/合作意向 → 写入资料库数据表 → 工作台可视化跟进。

```
采集器(Playwright) → 意向识别 → 去重 → 落CSV → 增量推库 → 工作台(实时读库)
```

---

## 1. 建两张数据表（WorkBuddy 资料库）

在 WorkBuddy 里打开「资料库」skill，新建一张表，命名 **「获客意向客户」**，字段如下：

| 字段 | 类型 | 选项/配置 |
|---|---|---|

| 评论内容 | 文本 | — |
| 行业分类 | 单选 | 家具行业 / 少儿编程 / 私教减脂 / 家装设计 / 二手车 / 医美 / 宠物服务 / 母婴早教 / 流量套餐 / 宽带 / 手机终端 / 靓号 / 融合套餐 / 副卡·亲情号 / 全屋光纤 FTTR / 政企·商铺 / 云电脑 / 智能穿戴 / 智家安防 / 视频会员 / 综合行业 |
| 意向等级 | 单选 | 高 / 中 / 低 |
| 意向分 | 数字 | — |
| 命中关键词 | 文本 | — |
| 采集关键词 | 文本 | — |
| 主页链接 | 文本 | — |
| 跟进状态 | 单选 | 待跟进 / 已联系 / 已加微 / 已成单 / 无效 |

再建一张表，命名 **「获客采集任务」**，字段如下：

| 字段 | 类型 | 选项/配置 |
|---|---|---|
| 关键词 | 文本 | — |
| 平台范围 | 文本 | — |
| 扫描内容 | 数字 | — |
| 识别意向 | 数字 | — |
| 高意向 | 数字 | — |

建完后，**分别复制两张表的 id**（形如 `MjDdEbw22n8gTgFBOrPurw`）。

---

## 2. 绑定表 id

在 skill 根目录（解压后的目录）打开终端：

```bash
python scripts/init_workspace.py --leads-db <获客意向客户表id> --tasks-db <获客采集任务表id>
```

输出 `✅ 初始化完成，共替换 N 处` 即成功。它会自动把表 id 写进
`workbench/huoke-radar.html`、`scripts/huoke_push.py`、`scripts/push_pending.py`（并备份为 `*.bak`）。

---

## 3. 部署工作台页面

用「资料库」skill 的「在线 page」能力，把 **`workbench/huoke-radar.html`** 发布上线，
得到**你自己的链接**。页面经 SDK 实时读表，打开即用。

---

## 4. 装依赖

```bash
# 方式 A：双击 scripts/install.bat
# 方式 B：
python -m pip install -r scripts/requirements.txt
```
> 依赖仅 `playwright>=1.40`。CDP 模式复用你本机 Chrome，**不需要** `playwright install chromium`（省几百 MB）。

---

## 5. 登录平台（一次性）

```bash
python scripts/init_session.py          # 引导登录抖音 + 小红书（会弹浏览器，扫码/手机号）
python scripts/init_session.py --check  # 查看登录态
```
> 弹出人机验证就手动滑一下（只做一次）。登录态存 `scripts/browser_data/`。

---

## 6. 采集

**方式 A · 工作台按钮（推荐）**
1. 双击 `scripts/start_agent.bat` —— 黑窗口保持开着；
2. 打开你的工作台链接 → 「采集任务」→ 选产品/渠道/地域 → 点「开始采集」；
3. 浏览器自动弹出采集，页面上有实时日志，采完自动写库。

**方式 B · 命令行**

```bash
python scripts/huoke_collector.py --mode browser --keyword 家具 减脂 --platform douyin xhs
python scripts/huoke_push.py scripts/data/huoke_leads_<批次>.csv
```

---

## 7. 采集后自动推（可选，推荐）

```bash
python scripts/push_pending.py --report   # 先看哪些批次还没入库
python scripts/push_pending.py            # 补齐全部未入库（幂等，可重复跑）
```

再在 WorkBuddy 建一个**每小时定时任务**执行 `push_pending.py`（每次现取 token），即可实现「采集后自动推」。
想定时采集：`python scripts/daily_run.py`（可配 `scripts/config.json` 的 `watch` 段）。

---

## 8. 验证

- 工作台「意向客户」能按 `行业分类`/`来源平台`/`意向等级` 筛选；
- 「今日要处理」置顶区能看到逾期/待跟进；
- 「采集任务」页有历史任务记录；
- 改跟进状态 → 刷新页面仍保留（已写库）。

## 🛠 常见坑

| 症状 | 原因/处理 |
|---|---|
| 采到 0 条 | `collected_cache.json` 断点缓存 → 换关键词或删该文件 |
| 小红书笔记 404 | 链接缺 `xsec_token` → 采集器已自动补，确认非改版 |
| 写库报「输入 JSON 为空」 | stdin 契约：第一行 token、第二行 JSON，键用 `database_id` |
| 页面连不上采集器 | `start_agent.bat` 黑窗口没开；云端 https 页访问本机被拦 → 用 `scripts/打开线索雷达.bat` 本地打开 |
| 登录态失效 | 重跑 `scripts/init_login.bat` |
| 无头过不了人机验证 | 去掉 `--headless` 手动滑一次 |
